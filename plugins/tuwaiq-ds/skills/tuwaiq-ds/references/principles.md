# المبادئ الـ٢٥ — لماذا نصمّم هكذا

> المرجع الملزم لأي تصميم أو تعديل واجهة. أي شاشة جديدة تُقاس على هذه المبادئ قبل التنفيذ.
> (وثّقها صاحب المنتج — 2026-07-06)

التوكنز تضمن **الاتساق**؛ هذه المبادئ تضمن **الجودة**. الفحص الآلي يمسك الأولى فقط،
فالثانية مسؤوليتك أنت.

| # | المبدأ | السؤال العملي قبل التنفيذ |
|---|--------|---------------------------|
| 1 | البساطة أولًا | هل هذا العنصر ضروري لفهم الميزة أو استخدامها؟ إن لا: احذف أو أجّل أو خفّف. |
| 2 | الأهم هو الأكبر | ما الشيء الأساسي في هذه الشاشة؟ هل يقود العين فعلًا؟ |
| 3 | لا حقول باردة | هل يستحق هذا الاختيار تجربة أجمل من Text Field؟ |
| 4 | متعة بلا زحمة | هل العنصر الممتع جعل المهمة أسهل، أم أطول؟ |
| 5 | لا «داشبورد تقليدي» | هل أستطيع الفصل بمسافة أو خلفية بدل الحد؟ |
| 6 | لا صور stock | هل الصورة تضيف هوية أو معنى؟ إن لا: احذفها. |
| 7 | التفاعل عند الحاجة | هل يحتاجه المستخدم الآن، أم يظهر عند التفاعل؟ |
| 8 | Popover / Modal / Sheet كأدوات | هل حجم الطبقة يساوي حجم القرار؟ |
| 9 | رحلة لا نموذج بيانات | هل أحوّل جدول قاعدة البيانات إلى حقول؟ (خطأ) |
| 10 | ابدأ بالنسخة الأخف | ما أقل شيء يكفي لإنشاء هذا الكيان؟ |
| 11 | الإعدادات ≠ الإنشاء | هل هذا الحقل يمكن أن يأتي بعد الإنشاء؟ |
| 12 | الخيارات الكبيرة بصرية | خيارات قليلة ومؤثرة → Cards/Pills/Segmented لا Dropdown. |
| 13 | نصوص خفيفة وواضحة | هل النص يوجّه، أم يشرح ويسوّق؟ |
| 14 | لكل شاشة مزاجها | نفس الخطوط والمسافات والأزرار، ومزاج مختلف. |
| 15 | صمّم للعربية من البداية | RTL ليس قلب اتجاه — طول الكلمات، الأرقام، أولوية المعلومة. |
| 16 | لا Card لكل شيء | البطاقة للكيان المستقل فقط. |
| 17 | الحالات أهم من الشكل الساكن | هل صمّمت: فارغ، تحميل، خطأ، لا صلاحية، نجاح، خطير؟ |
| 18 | نظام إداري إنساني | لغة واضحة، رسائل هادئة، فراغ مريح. |
| 19 | الجدول عند الحاجة فقط | هل يحتاج فرزًا/بحثًا/مقارنة/تحديدًا جماعيًا؟ إن لا: لا جدول. |
| 20 | إجراءات قليلة وواضحة | إجراء رئيسي واحد. لا خمسة أزرار بنفس الوزن. |
| 21 | لا تشرح التعقيد، أعد تصميمه | يحتاج نصًا طويلًا ليُفهم؟ العنصر نفسه غلط. |
| 22 | التفاصيل موجودة لا مزاحمة | متاحة في Advanced / Sheet / Popover، لا مفروضة. |
| 23 | إحساس بالمنتج لا زينة | الجمال من التراتبية والمسافات والحذف. |
| 24 | كل تفاعل يعطي سيطرة | فيدباك بعد كل إجراء، وتراجع متى أمكن. |
| 25 | نظيف وبسيط وذكي — لا بارد | احذف الزائد، أبرز المهم، وحوّل القرارات الصغيرة للحظات جميلة. |

**الهدف: منتج عملي، بسيط، عربي، واضح، وله روح.**
