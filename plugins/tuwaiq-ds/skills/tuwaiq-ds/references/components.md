# المكوّنات — ماذا أستخدم ومتى

المكوّنات الجاهزة للنسخ: `../assets/primitives/`.
**قاعدة:** ما فيه مكوّن مناسب؟ وسّع الموجود بـ prop. لا تنسخ مكوّنًا وتعدّله، ولا تكتب عنصرًا خامًا.

---

## الأزرار — `<TuwayqButton>`

```tsx
<TuwayqButton variant="primary" icon={<Plus size={18} />} onClick={…}>
  {t("clubs.create")}
</TuwayqButton>
```

| variant | الشكل | متى |
|---------|-------|-----|
| `primary` | `--brand` + `--brand-fg` | الإجراء الرئيسي — **واحد فقط** في الشاشة |
| `secondary` | `--brand-tint` + `--brand` | إجراء مساند بجانب الرئيسي |
| `ghost` | شفاف + `--text` | إجراء خفيف داخل صف أو بطاقة |
| `danger` | `--danger-tint` + `--danger` | حذف/رفض — **دائمًا مع `<ConfirmDialog>`** |

كل الأزرار `--radius-full`، ارتفاع `--control-height`، نص `.t-body-lg`.
الأيقونة **بعد** النص في الـ JSX (يظهر يمينه في RTL). حالة `disabled` تخفض العتامة لا تغيّر اللون.
زر التحميل: `loading` prop → سبنر مكان الأيقونة والزر معطّل — لا تستبدل النص.

---

## الشارات والحالات — `<Badge>`

```tsx
<Badge label={t("status.published")} variant="success" dot />
```
`variant`: `brand` · `success` · `warning` · `danger` · `info` · `neutral`
كل شارة = `<tint>` خلفية + اللون الأساسي نصًا. `dot` للحالات الحيّة (نشط/متوقف).
**الشارة للحالة فقط** — لا تستخدمها كزر ولا كفلتر.

---

## الحقول — `<Field>`

```tsx
<Field
  label={t("club.name")}
  value={name}
  onChange={setName}
  hint={t("club.nameHint")}
  error={errors.name}
  required
/>
```
ارتفاع `--field-height`، خلفية `--surface-2`، زاوية `--radius-md`، بلا حد.
اللابل فوق الحقل دائمًا (لا placeholder كبديل عن اللابل).
الخطأ تحت الحقل بـ `--danger` و`.t-caption` + أيقونة.
`dir="ltr"` للحقول التي تستقبل رابطًا أو بريدًا أو أرقامًا لاتينية فقط.

**قبل ما تضيف حقلًا اسأل:** هل يستحق أن يكون اختيارًا بصريًا بدل حقل؟ (مبدأ ٣ و١٢)

## الاختيار

| عدد الخيارات | المكوّن |
|--------------|---------|
| 2–3 متنافية | `<SegmentedToggle>` |
| 3–6 مؤثرة | `<ChoiceCards>` أو `<Pills>` |
| 7+ أو ثانوية | `<Select>` (دروب داون) |
| متعدّد + بحث | `<FilterDropdown>` |

**لا دروب داون لخيارين.** (مبدأ ١٢)

---

## العرض

| المكوّن | متى |
|---------|-----|
| `<PageHeader title subtitle action>` | أعلى كل صفحة — عنوان واحد + إجراء رئيسي واحد |
| `<StatCard label value icon trend hint>` | مؤشّر رقمي في صف KPI (٤ → ٢ → ١ حسب العرض) |
| `<EmptyState icon title description action>` | **إلزامي** لكل قائمة أو جدول أو شبكة |
| `<TuwayqTable>` | فقط عند الحاجة لفرز/بحث/مقارنة/إجراءات جماعية (مبدأ ١٩) |
| `<CoverArt>` | صورة كيان — مع بديل مولّد من الحروف عند غيابها، لا صورة stock |

**البطاقة للكيان المستقل فقط** (نادٍ، فعالية، عضو، طلب). لا بطاقة حول كل حقل (مبدأ ١٦).

---

## الطبقات

| المكوّن | متى | التفاصيل |
|---------|-----|----------|
| `<Popover>` | قرار صغير سريع مرتبط بعنصر | زاوية `--radius-lg`، ظل `--shadow-2`، `--dur-base` |
| `<Modal>` | قرار يحتاج تركيز | زاوية `--radius-xl`، ظل `--shadow-3`، خلفية معتمة |
| `<SideSheet>` | تفاصيل وإعدادات | يفتح من جهة البداية في RTL، عرض 480px، `--dur-slow` |
| `<ConfirmDialog>` | كل إجراء لا رجعة فيه | زر التأكيد `danger`، والنص يذكر **ماذا سيُحذف بالضبط** |
| `<Toast>` | تأكيد بعد الإجراء | 3 ثوانٍ، مع «تراجع» إذا الإجراء قابل للتراجع |

**لا مودال لقرار صغير، ولا دفن إجراء مهم في قائمة صغيرة.** (مبدأ ٨)

---

## ما لا يُبنى أبدًا

- عنصر HTML خام تفاعلي (`<button>` `<input>` `<select>` `<table>` `<dialog>`) خارج `primitives/`
- مكتبة UI خارجية (MUI, AntD, Chakra, DaisyUI) — تكسر النظام كاملًا
- أيقونات من مصادر مختلطة — **lucide-react فقط**، مقاس 16/18/20/24، `aria-hidden` إذا معها نص
- صور stock عامة (مبدأ ٦)
