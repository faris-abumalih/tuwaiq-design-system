# الحالات — المنتج الحقيقي يعيش هنا (مبدأ ١٧)

كل شاشة تُسلَّم بحالاتها. شاشة بلا حالة فارغة = شاشة نصف مصمَّمة.

## القائمة الإلزامية

| الحالة | متى | الشكل |
|--------|-----|-------|
| **فارغة — أول مرة** | لا بيانات إطلاقًا | أيقونة خفيفة + عنوان + سطر شرح + **زر الإجراء الأول**. بلا صورة stock. |
| **فارغة — بعد فلترة** | فلتر/بحث بلا نتائج | «ما فيه نتائج لـ ‹س›» + زر «مسح الفلاتر». مختلفة عن الحالة الأولى. |
| **تحميل** | جلب أول | هيكل عظمي بنفس شكل المحتوى القادم. لا سبنر يملأ الشاشة. |
| **تحميل جزئي** | إجراء على عنصر | سبنر داخل الزر فقط، الباقي يشتغل. |
| **خطأ** | فشل الجلب | ماذا فشل + سبب مفهوم + زر «إعادة المحاولة». بلا رمز خطأ خام. |
| **بلا صلاحية** | المستخدم لا يملك الوصول | اشرح مَن يملكها وكيف يطلبها. لا تُخفِ الشيء بصمت. |
| **نجاح** | بعد إجراء | توست 3 ثوانٍ + «تراجع» إن أمكن. |
| **إجراء خطير** | حذف/رفض/إلغاء | `<ConfirmDialog>` يذكر الاسم بالضبط، وزر التأكيد `danger`. |
| **اكتمال جزئي** | بيانات ناقصة | أظهر الموجود + تلميح لطيف لما ينقص. لا تُخفِ الصفحة. |
| **بيانات كثيرة** | 100+ عنصر | ترقيم أو تحميل تدريجي + بحث + فلاتر. |

## قوالب

**فارغة (أول مرة)**
```tsx
<EmptyState
  icon={<CalendarPlus size={28} />}
  title={t("events.empty.title")}          // «ما فيه فعاليات بعد»
  description={t("events.empty.desc")}     // سطر واحد يشرح القيمة
  action={<TuwayqButton>{t("events.create")}</TuwayqButton>}
/>
```

**خطأ**
```tsx
<EmptyState
  variant="error"
  title={t("errors.loadFailed.title")}     // «ما قدرنا نحمّل الفعاليات»
  description={t("errors.loadFailed.desc")}// «تحقق من الاتصال وحاول مرة ثانية»
  action={<TuwayqButton variant="secondary" onClick={retry}>{t("common.retry")}</TuwayqButton>}
/>
```

**خطير**
```tsx
<ConfirmDialog
  tone="danger"
  title={t("clubs.delete.title", { name: club.name })}   // «حذف نادي ‹التقنية›؟»
  description={t("clubs.delete.desc")}                    // ماذا سيُفقد بالضبط
  confirmLabel={t("common.delete")}
  onConfirm={remove}
/>
```

## قواعد الشعور

- **بعد كل إجراء يجي فيدباك** — بلا استثناء (مبدأ ٢٤).
- الخطأ يقول ماذا نفعل بعده، لا ماذا انكسر فقط.
- لا تُخفِ نتيجة إجراء ناجح خلف تحديث صامت.
- التراجع أفضل من طلب التأكيد، متى ما كان ممكنًا.
