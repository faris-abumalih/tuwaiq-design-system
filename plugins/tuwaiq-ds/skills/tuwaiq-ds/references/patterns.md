# الأنماط — كيف تُبنى الشاشة

## تخطيط الصفحة (ويب)

```
┌──────────────────────────────── سايدبار على اليمين (RTL) ──┐
│  المحتوى: max-width 1280 · هامش 24                          │
│  ┌ PageHeader: عنوان + وصف قصير + إجراء رئيسي واحد ───────┐ │
│  ├ (اختياري) صف KPI: 4 → 2 → 1 ───────────────────────────┤ │
│  ├ شريط أدوات: بحث + فلاتر (يظهر فقط لو فيه بيانات) ──────┤ │
│  └ المحتوى: بطاقات أو جدول أو قائمة ─────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```
- بين الأقسام: `32`. داخل القسم: `16`.
- السايدبار `--sidebar-width` ويبدأ من جهة البداية في RTL (أي اليمين).
- الصفحة تنفس: لا تملأ العرض بالكامل بالبطاقات إذا المحتوى قليل.

## اختيار الطبقة

| القرار | المكوّن | مثال |
|--------|---------|------|
| صغير ومرتبط بعنصر | Popover | اختيار وقت، عدد، منصة تواصل، لون، إجراء صف |
| يحتاج تركيزًا | Modal | إنشاء كيان، تأكيد مهم، بيانات مركّبة |
| تفاصيل وإعدادات | Side Sheet | إعدادات فعالية، تعديل كيان، ملف عضو |
| صفحة كاملة | Route | رحلة متعددة الخطوات، أو محتوى يستحق رابطًا |

القاعدة: **حجم الطبقة يساوي حجم القرار.**

## النماذج

1. أهم حقل أولًا وأكبر بصريًا (اسم الكيان مثلًا) — مبدأ ٢.
2. النسخة الأخف: ٥–٦ حقول للإنشاء، والباقي في الإعدادات — مبدأ ١٠ و١١.
3. حوّل ما يمكن إلى اختيار بصري بدل حقل بارد — مبدأ ٣ و١٢.
4. التحقق عند مغادرة الحقل (blur)، لا مع كل حرف.
5. زر الحفظ معطّل حتى يصير النموذج صالحًا، مع سبب واضح عند التعطيل.
6. حارس المغادرة: نموذج فيه تعديل غير محفوظ → تأكيد قبل الخروج.

## الجداول — فقط عند الحاجة

استخدم جدولًا **فقط** إذا احتاج المستخدم: فرزًا، بحثًا، مقارنة صف بصف، تحديدًا جماعيًا،
أو قراءة بيانات كثيرة بسرعة. غير ذلك: بطاقات أو قائمة.

إذا استخدمت جدولًا:
- رأس `--surface-3`، صفوف بلا حدود، فاصل `--hairline` أو تباين خلفية فقط.
- أول عمود = هوية الصف (صورة + اسم)، وفي RTL يبدأ من اليمين.
- الأرقام محاذاة `end`، النص محاذاة `start`.
- إجراءات الصف في آخر عمود، تظهر عند hover، وفي قائمة إذا زادت عن ٢.
- ترقيم أو تحميل تدريجي بعد 25 صفًا.
- **حالة فارغة إلزامية** بنفس عرض الجدول.

## الشبكات

| المحتوى | الشبكة |
|---------|--------|
| KPI | 4 → 2 → 1 (فواصل 1024 / 640) |
| بطاقات كيانات | 3 → 2 → 1 |
| قائمة تفاصيل | عمود واحد دائمًا |

الفجوة `16`. البطاقات في الصف بنفس الارتفاع (`align-items: stretch`).

## الحركة

| الحدث | المدة | الحركة |
|-------|-------|--------|
| hover / تغيّر لون | `--dur-fast` | لون فقط |
| بوبوفر / دروب داون | `--dur-base` | opacity + 4px انزلاق + scale .97 |
| مودال | `--dur-slow` | opacity + scale .96 |
| سايد شيت | `--dur-slow` | انزلاق من جهة البداية |
| توست | `--dur-base` | انزلاق من الأسفل |

بلا ارتداد (overshoot)، وبلا حركة تعيق الإجراء.

## الأداء المحسوس

- هيكل عظمي (skeleton) للتحميل الأول، لا سبنر يملأ الشاشة.
- تحديث متفائل للإجراءات السريعة (إعجاب، تثبيت، أرشفة) مع تراجع عند الفشل.
- لا تُقفل الشاشة كاملة لأجل عملية على عنصر واحد.
