# قائمة التسليم

امشِ عليها قبل ما تقول «خلصت». الفحص الآلي يغطي القسم الأول فقط.

## القرارات (قبل كل شيء — `design-thinking.md`)
- [ ] أقدر أشرح **لماذا هذه الحاوية** بجملة تتعلق بأهمية الإجراء في المنتج
- [ ] فيه بطل واحد، ومعروض بمقاس العنوان بلا لابل
- [ ] الحقول الظاهرة ٦ أو أقل — والباقي مطوي أو مؤجّل للإعدادات
- [ ] ما استخدمت `*` على المطلوب كبديل عن الطي
- [ ] كل اختيار شكله مناسب لطبيعته (كاردات / pills / stepper / دروب داون)
- [ ] ما فيه `type="date"` ولا `type="time"` أصلي
- [ ] إذا فيه شيء شكله هو وظيفته، فالإدخال داخل معاينته
- [ ] لحظة ممتعة واحدة أو اثنتان — لا صفر ولا ثلاث
- [ ] أقدر أحذف عنصرًا وتبقى الشاشة مفهومة؟ إذًا احذفه

## آليًا (يُرفض تلقائيًا)
- [ ] `python3 "$CLAUDE_PLUGIN_ROOT/scripts/ds_lint.py" src` → صفر أخطاء
- [ ] ما فيه لون/مقاس/زاوية/خط مكتوب يدويًا
- [ ] ما فيه خاصية اتجاهية فيزيائية
- [ ] ما فيه عنصر HTML خام تفاعلي خارج `primitives/`
- [ ] كل نص ظاهر عبر `t()`

## التصميم (مسؤوليتك)
- [ ] عنوان صفحة واحد، وإجراء رئيسي واحد
- [ ] الأهم أكبر وأوضح — العين تعرف وين تروح (مبدأ ٢)
- [ ] ما فيه عنصر بلا سبب (مبدأ ١)
- [ ] الجدول مبرَّر بفرز/بحث/مقارنة، وإلا بطاقات (مبدأ ١٩)
- [ ] الخيارات القليلة بصرية لا دروب داون (مبدأ ١٢)
- [ ] حجم الطبقة = حجم القرار (مبدأ ٨)
- [ ] الفصل بمسافة قبل الحد (مبدأ ٥)
- [ ] ما فيه صورة stock (مبدأ ٦)

## الحالات
- [ ] فارغة (أول مرة) + فارغة (بعد فلترة)
- [ ] تحميل بهيكل عظمي
- [ ] خطأ مع «إعادة المحاولة»
- [ ] بلا صلاحية
- [ ] نجاح بتوست، وتراجع إن أمكن
- [ ] تأكيد لكل إجراء لا رجعة فيه، يذكر الاسم بالضبط

## العربية
- [ ] الشاشة مختبرة بـ `dir="rtl"` فعليًا
- [ ] أطول نص عربي متوقّع ما يكسر زرًّا ولا خلية
- [ ] الأيقونات الاتجاهية منعكسة، وغير الاتجاهية لا
- [ ] التواريخ والأرقام بصيغة النظام

## الوصولية
- [ ] تباين ≥ 4.5:1 لكل نص يُقرأ
- [ ] أهداف اللمس ≥ 44px
- [ ] `aria-label` لكل أيقونة بلا نص
- [ ] التنقل بالكيبورد يشتغل، والتركيز مرئي
- [ ] `prefers-reduced-motion` محترم
