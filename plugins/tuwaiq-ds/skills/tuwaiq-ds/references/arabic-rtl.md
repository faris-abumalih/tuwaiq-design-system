# العربية و RTL — القواعد غير القابلة للتفاوض

**الواجهة العربية الجيدة ليست قلب الاتجاه** (مبدأ ١٥). هذه القواعد تُفحص آليًا.

## 1. الخصائص المنطقية فقط

| ✗ ممنوع | ✓ المطلوب |
|---------|-----------|
| `marginLeft` / `marginRight` | `marginInlineStart` / `marginInlineEnd` |
| `paddingLeft` / `paddingRight` | `paddingInlineStart` / `paddingInlineEnd` |
| `left` / `right` | `insetInlineStart` / `insetInlineEnd` |
| `borderLeft` / `borderRight` | `borderInlineStart` / `borderInlineEnd` |
| `textAlign: "left" / "right"` | `textAlign: "start" / "end"` |
| `ml-*` `mr-*` `pl-*` `pr-*` | `ms-*` `me-*` `ps-*` `pe-*` |
| `text-left` `text-right` | `text-start` `text-end` |
| `rounded-l-*` `rounded-r-*` | `rounded-s-*` `rounded-e-*` |

الاستثناء الوحيد: إحداثيات محسوبة من `getBoundingClientRect` لطبقة portal —
وقتها وثّقها: `// ds-allow: rtl-logical-props — إحداثي محسوب من قياس العنصر`.

## 2. الاتجاه

- الاتجاه يُضبط مرة واحدة على `<html dir>` من i18n. **لا `dir="rtl"` مبعثر في المكوّنات.**
- `dir="ltr"` مسموح ومطلوب لـ: الروابط، البريد، المعرّفات، الأكواد، الرسوم البيانية.
- `dir="auto"` للمحتوى الذي يكتبه المستخدم وقد يكون بأي لغة.
- حقل فارغ بـ `dir="auto"` يرجع LTR — استخدم `dir="rtl"` صراحة للحقول العربية بالتأكيد.

## 3. ترتيب العناصر

- في الصف، **الأهم أولًا في الـ JSX** — يظهر يمينًا في RTL تلقائيًا.
- الأيقونة بعد النص في الكود = يمين النص بصريًا.
- أيقونات الاتجاه (سهم رجوع، «التالي») تنعكس: استخدم `ChevronRight` للرجوع في RTL،
  أو اقلبها بـ `transform: scaleX(-1)` عبر `[dir="rtl"] &`.
- الأيقونات غير الاتجاهية (بحث، إعدادات، حذف) **لا تنعكس**.
- شريط التقدّم يمتلئ من اليمين لليسار.

## 4. النص

- الخط `--font-family` فقط، والأوزان 400/500/600 — العربية بلا وزن 300 أو 700.
- ارتفاع السطر العربي `1.6` للنص و`1.4` للعناوين — أعلى من اللاتيني.
- **لا تقطع الكلمة العربية** (`word-break: keep-all`)، واستخدم `text-overflow: ellipsis` بحذر.
- الكلمات العربية أطول: احسب مساحة الأزرار على أطول نص متوقّع، لا على «حفظ».
- بلا `text-transform` (لا معنى له عربيًا).

## 5. الأرقام والتواريخ

- أرقام لاتينية (`0-9`) في كل الواجهة — أوضح للقراءة السريعة ومتّسقة مع البيانات.
- التاريخ: `12 مارس 2026` — لا `2026/03/12`.
- الوقت 12 ساعة مع «ص/م».
- المدة: «ساعتان و30 دقيقة» لا `2:30`.
- الأرقام دائمًا `dir="ltr"` داخل نص عربي إذا فيها رموز (`+966 5x`, `12.5%`).

## 6. النصوص

- كل نص ظاهر عبر `t("key")` — بلا استثناء، حتى «نعم» و«لا».
- المفاتيح إنجليزية بنمط `page.section.item`.
- لغة قصيرة ومباشرة: «حذف النادي» لا «هل أنت متأكد من رغبتك في إجراء عملية الحذف؟»
- بلا لغة تسويقية داخل أدوات العمل (مبدأ ١٣).

## 7. الوصولية

- تباين النص الأساسي ≥ 4.5:1 (`--text` على `--surface` = يمر).
- `--text-faint` للـ placeholder فقط — **ليس لنص يجب قراءته**.
- كل هدف لمس ≥ `--touch-min` (44px).
- كل أيقونة بلا نص تحتاج `aria-label` من `t()`.
- التركيز مرئي دائمًا: `:focus-visible` بحلقة `--brand` (في `theme.css`).
- اللون وحده لا ينقل الحالة — أضِف أيقونة أو نصًا.
