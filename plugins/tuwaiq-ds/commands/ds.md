الطلب: **$ARGUMENTS**

**إلزامي أولًا:** استدعِ مهارة `tuwaiq-ds`.

أنت مسؤول عن كل شيء في هذا المسار. **لا تسأل المستخدم عن خطوة إدارية** — الشيء الوحيد
الذي يستحق وقفة هو **بطاقة القرارات** وأي تعارض حقيقي مع إعداد قائم.

## أولًا: اقرأ حالة المشروع بصمت

```bash
ls package.json src/styles/theme.css ds.config.json 2>/dev/null
```

| ما وجدته | ما تفعله |
|----------|----------|
| المجلد فاضٍ | جهّز مشروعًا: `npm create vite@latest . -- --template react-ts` ثم `npm i` ثم `npm i react-i18next i18next lucide-react react-router-dom` و `npm i -D tailwindcss @tailwindcss/vite` → ثم رتّب النظام (تحت) |
| مشروع بلا `theme.css` | رتّب النظام (تحت) |
| النظام مركّب أصلًا | تجاوز، وانتقل مباشرة للمرحلة ١ |
| فيه مكتبة UI خارجية أو `theme.css` مختلف | **قف واسأل** — هذا تعارض حقيقي، لا تدهسه |

**ترتيب النظام** (نفّذه بلا سؤال، ثم اذكره في ٣ أسطر):
```bash
mkdir -p src/styles src/app/components/primitives src/app/locales/ar .github/workflows
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/gen_theme.py" src/styles/theme.css
cp "${CLAUDE_PLUGIN_ROOT}/skills/tuwaiq-ds/assets/primitives/"* src/app/components/primitives/
cp "${CLAUDE_PLUGIN_ROOT}/skills/tuwaiq-ds/assets/ds.config.example.json" ds.config.json
cp "${CLAUDE_PLUGIN_ROOT}/skills/tuwaiq-ds/assets/ds-lint.yml" .github/workflows/
```
ثم: اربط `theme.css` و `motion.css` في `src/styles/index.css`، اضبط `<html lang="ar" dir="rtl">`،
جهّز i18n، وألحق `assets/CLAUDE.md.snippet` بـ `CLAUDE.md`.

## ثانيًا: وجّه الطلب

| نوع الطلب | ما تفعله |
|-----------|----------|
| بناء شاشة/ميزة/موقع | المرحلة ١ → ٢ → ٣ |
| «راجع» · «افحص» · بلا طلب | المرحلة ٣ فقط، على `src` أو على `git diff` |
| «أعد التفكير في…» · «ليش كذا؟» | المرحلة ١ فقط — **بلا كود**، ثم اسأل قبل أي تنفيذ |
| «أي توكن…» · «أي مكوّن…» | جاوب من `references/tokens.md` أو `components.md` — لا تخترع، ولا تضف توكنًا محليًا |
| موقع كامل | كرّر ١→٢ لكل شاشة، وابدأ بأهم شاشة لا بالأسهل |

## المرحلة ١ — بطاقة القرارات (لا كود هنا إطلاقًا)

اقرأ `references/design-thinking.md`، واعرض البطاقة مملوءة بجُمَل محدّدة.
«حسب الحالة» ليست إجابة:

```
الحاوية:   <صفحة / مودال / شيت / بوبوفر> — لأن <وزن الإجراء في المنتج>
البطل:     <اسم الحقل> — بمقاس العنوان بلا لابل
ظاهر:      <ما يمنع غيابه الإنشاء — ٦ أو أقل>
مطوي:      <«خيارات متقدمة»>
مؤجّل:     <ينتقل لصفحة الكيان/الإعدادات ولا يظهر هنا>
الاختيارات: <لكل اختيار: الشكل + السبب>
الدمج:     <شيء شكله هو وظيفته؟ أين يوضع الإدخال؟>
اللحظة:    <واحدة أو اثنتان>
الحالات:   <فارغة أولى · فارغة بعد فلترة · تحميل · خطأ · بلا صلاحية · نجاح>
```

راجعها بنفسك قبل العرض: أكثر من ٦ حقول ظاهرة؟ `*` بدل الطي؟ كل الحقول بنفس الوزن؟
مودال لإجراء أساسي؟ `<select>` لكيانات لها هوية بصرية؟ `type="date"` أو `type="time"`؟
أي واحدة من هذي = ارجع وأعد القرار قبل ما تعرض.

**اعرض البطاقة وانتظر الموافقة. هذه الوقفة الوحيدة في المسار.**
